MOTORES DE PREDICCIÓN

10 motores de análisis independiente

Desde estadística clásica hasta deep learning con LSTM. Cada motor analiza los datos desde una perspectiva diferente.

📊

Frequency Analysis

Frecuencia histórica con Z-scores y test chi-cuadrado de uniformidad.

+4.0% vs azar0.2ms
🔥

Hot/Cold Tracker

Temperatura de números (-1.0 a +1.0) con probabilidad de mean reversion.

+15.6%0.2ms
⏰

Gap Analysis

Detección de números overdue. ¿Cuánto hace que no sale cada número?

+30.0%0.1ms
🔗

Markov Chain

Transiciones de 1° y 2° orden. El único motor estadísticamente significativo.

★ +63.2%1ms
🎲

Bayesian Inference

Beta posterior con credible intervals. Actualización de creencias con cada sorteo.

+14.1%0.2ms
🔍

Pattern Detection

Pares consecutivos, sumas, par/impar, runs test de aleatoriedad.

+28.6%1ms
📡

Entropy Scoring

Entropía de Shannon + autocorrelación. ¿Es la secuencia realmente aleatoria?

+15.5%2ms
🎯

Monte Carlo

10,000 simulaciones con PRNG mulberry32. Percentiles P10/P50/P90.

+11.1%600ms
🧠

LSTM Neural Network

Deep learning con TensorFlow 2.21. Bidirectional LSTM con Dropout.

+26.3%16s
⚙️

Ensemble

Combina los 8 motores anteriores con pesos ponderados. El más robusto.

+50.0%700ms

RESULTADOS

Hallazgos clave del análisis riguroso

Permutation tests con corrección Bonferroni. Solo reportamos lo que es estadísticamente significativo.

🔗 Markov Chain en EuroMillions

+63.2%

Mejora vs azar en backtesting. p-value = 0.0000 (altamente significativo tras Bonferroni). Cohen's d = 3.148 (large effect).

✅ Único motor estadísticamente significativo

📊 Expected Value Calculator

-79%

EV por dólar en EuroMillions con jackpot mínimo. Break-even: $294M (imposible). Solo Pozo Millonario tiene break-even alcanzable ($3.5M).

❌ Ninguna lotería tiene EV positivo

💰 Kelly Criterion

≈0

Kelly fraction para todas las loterías. La probabilidad de jackpot es tan baja que ni fraccional Kelly recomienda apostar. Monte Carlo: 100% bancarrota en 100 sorteos.

❌ No apostar — EV negativo

🎰 Lotería más predecible

UK49s

5,863 sorteos analizados. Ensemble logra +50% mejora vs azar. Pero pool 6/49 hace jackpot 1:685M.

⚠️ Predecible pero jackpot inalcanzable

🚨 Detección de trampa

35%

De sorteos del Pozo Millonario tienen patrones estadísticamente sospechosos (4+ consecutivos, todos pares/impares). EuroMillions: 4 números no aleatorios.

EMPEZAR

Quick Start en 3 pasos

# 1. Clonar el repositorio
git clone https://github.com/edgarfloresguerra2011-a11y/lottery-predictor.git
cd lottery-predictor

# 2. Instalar dependencias Python
pip install tensorflow aiohttp beautifulsoup4 openpyxl matplotlib

# 3. Ejecutar predicción
cd scripts/lottery_predictor
python3 main.py --lottery euromillions --engine markov_chain --predict

# 🎯 Output:
# 🎯 PREDICCIÓN: 50 21 42 29 23
# Último sorteo #1977 (2026-09-22): 13 14 16 44 50

# 🌐 Iniciar Web UI
cd /home/z/my-project && bun run dev
# → http://localhost:3000

# 🔌 Iniciar MCP Server
python3 mcp_server.py
# → http://localhost:8787/mcp
