Quick Start

Empieza en 60 segundos.

Open source. MIT. Sin dependencias raras.

user@local: ~
# 1. Clonar el repositorio $ git clone https://github.com/user/lottery-predictor.git $ cd lottery-predictor # 2. Instalar dependencias $ pip install -r requirements.txt ✓ Installed 24 packages in 3.2s # 3. Analizar EuroMillions con Markov Chain $ python predict.py --lottery euromillions --engine markov Loading 8,420 draws.................. done Building transition matrix........... done Chi-square test: p=0.0000 ✓ significant Cohen's d = 3.148 (large effect) Improvement over random: +63.2% # 4. Lanzar MCP server (6 tools) $ python -m lottery_predictor.mcp --serve MCP server listening on :8080 Tools: predict · analyze · backtest · cheating_detect · ev_calc · kelly ⚠ EV = −79% per $ · Kelly ≈ 0 · No apostar
